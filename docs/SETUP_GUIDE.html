NoxBrain Solar Monitor

শুরু থেকে শেষ পর্যন্ত Setup নির্দেশনা · Firmware 1.1.1 ও নতুন app অনুযায়ী

যা যা লাগবে

  • ESP32 বা ESP32-S3 board (কমপক্ষে 4MB flash)
  • Data USB cable (শুধু charging cable হলে চলবে না)
  • Windows, Mac বা Linux computer, সাথে Google Chrome অথবা Microsoft Edge browser
    • Chrome: https://www.google.com/chrome/
    • Edge: https://www.microsoft.com/edge
  • Android phone, Android 10 বা তার পরের version
  • বাড়ির 2.4 GHz Wi-Fi (5 GHz Wi-Fi-তে ESP32 যুক্ত হতে পারে না)
  • SRNE Shiner solar charge controller। সমর্থিত model: Shiner2410, 2420, 2430, 2440, 2460
  • JK Smart BMS (না থাকলেও চলবে)
  • একটা Google account (Firebase-এর জন্য, বিনামূল্যে)

ধাপ ১: Google account তৈরি

আগে থেকে Gmail থাকলে এই ধাপ বাদ দিন।

  1. যান: https://accounts.google.com/signup
  2. নাম, জন্মতারিখ আর password দিয়ে account তৈরি করুন।

ধাপ ২: নিজের Firebase project তৈরি

প্রত্যেক ব্যবহারকারীর data থাকে তার নিজের Firebase-এ, অন্য কেউ দেখতে পারে না। বিনামূল্যের Spark plan-ই যথেষ্ট, কোনো card লাগে না।

  1. যান: https://console.firebase.google.com/ এবং Google account দিয়ে login করুন।
  2. "Create a project" (বা "Add project") চাপুন।
  3. Project-এর একটা নাম দিন, যেমন my-solar। Continue চাপুন।
  4. Google Analytics লাগবে না, বন্ধ রাখতে পারেন। Create project চাপুন, তৈরি হলে Continue।

ধাপ ৩: Email/Password login চালু করা ও নিজের account তৈরি

  1. বাম পাশের মেনু থেকে Build → Authentication, তারপর Get started।
  2. Sign-in method tab-এ Email/Password বেছে নিন। প্রথম switch (Enable) চালু করে Save চাপুন।
  3. Users tab-এ Add user চাপুন। নিজের একটা email আর একটা শক্ত password দিন, তারপর Add user।
    এই email আর password পরে app-এ লাগবে। এটা Firebase-এর আলাদা login, আপনার Gmail-এর password না।
  4. Settings tab-এ User actions অংশে "Enable create (sign-up)" চালু রাখুন। এমনিতেই চালু থাকে। App প্রতিটা gateway-এর জন্য একটা আলাদা সীমিত account নিজেই তৈরি করে, তাই এটা চালু থাকতে হবে।

ধাপ ৪: Realtime Database তৈরি

  1. বাম মেনু থেকে Build → Realtime Database, তারপর Create Database।
  2. Location হিসেবে কাছের অঞ্চল বেছে নিন, যেমন Singapore (asia-southeast1)। Next।
  3. "Start in locked mode" বেছে নিয়ে Enable চাপুন।
  4. Database তৈরি হলে উপরে একটা link দেখাবে, যেমন https://my-solar-default-rtdb.asia-southeast1.firebasedatabase.app। এটাই Database URL। পরে লাগবে, কপি করে রাখুন।

ধাপ ৫: Web App register করে API Key নেওয়া

  1. বাম মেনুর উপরে ⚙ (gear) চেপে Project settings খুলুন।
  2. General tab-এ নিচে "Your apps" অংশে </> (Web) চিহ্ন চাপুন।
  3. App-এর একটা নাম দিন, যেমন noxbrain। Firebase Hosting চালু করবেন না। Register app চাপুন।
  4. একটা firebaseConfig code দেখাবে। পুরো code-টা কপি করে রাখুন। এর মধ্যে apiKey আর databaseURL আছে। databaseURL না থাকলে ধাপ ৪-এর Database URL ব্যবহার করবেন।

ধাপ ৬: NoxBrain Android app install

  1. Phone থেকে এই link-এ যান: [APK download link এখানে বসবে]
    Release হলে APK থাকবে https://noxbrain.com/solarapp/ ঠিকানায়, file-এর নাম NoxBrain_Solar_<version>.apk।
  2. Download শেষ হলে file খুলুন। Android "unknown apps install"-এর অনুমতি চাইলে, যে browser থেকে download করেছেন তাকে অনুমতি দিন।
  3. Install চাপুন। আগে পুরোনো কোনো NoxBrain app থাকলে, আর install না হলে, পুরোনোটা একবার uninstall করে আবার install করুন। এরপর থেকে app নিজে থেকেই update হবে।

ধাপ ৭: ESP32-এ firmware flash (এই website থেকে)

  1. ESP32 board-টা data cable দিয়ে computer-এ লাগান।
  2. Chrome বা Edge-এ এই পাতা খুলুন। Firmware যাচাই শেষ হলে "Connect & Install Firmware" বোতাম দেখাবে।
  3. বোতাম চাপুন। তালিকা থেকে ESP32-এর USB port বেছে নিন, যেমন "USB Serial", "CP210x" বা "CH340"। তারপর Connect।
  4. Install চাপুন। কয়েক মিনিট অপেক্ষা করুন, শেষ না হওয়া পর্যন্ত cable খুলবেন না।
  5. শেষ হলে ESP32 নিজে restart হবে, আর NoxBrain-XXXXXX নামের একটা setup Wi-Fi চালু করবে।

সমস্যা হলে:

  • Port দেখা না গেলে: অন্য cable দিয়ে চেষ্টা করুন, অথবা driver install করুন।
    • CP210x: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
    • CH340: https://www.wch-ic.com/downloads/CH341SER_EXE.html
  • Connect না হলে: ESP32-এর BOOT বোতাম চেপে ধরে cable আবার লাগান, তারপর আবার চেষ্টা করুন।

ধাপ ৮: App-এর Setup Wizard (৫টি ধাপ)

App খুললেই Setup শুরু হবে। উপরে "১/৫, ২/৫…" করে দেখাবে কোন ধাপে আছেন।

ধাপ ৮.১: Battery mode বেছে নেওয়া

  • Only Controller Mode: BMS নেই, যেমন Flooded বা Sealed lead-acid battery। Battery-র মান (SOC, Remaining Ah, current) controller-এর data থেকে হিসাব করে দেখানো হবে।
    শর্ত: সব load controller-এর Load terminal-এ থাকতে হবে। Inverter সরাসরি battery-তে লাগানো থাকলে হিসাব ভুল হবে।
  • Controller + BMS Mode: JK BMS আছে। Battery-র সব মান BMS থেকে নেওয়া হবে।

একটা বেছে নিয়ে "পরের ধাপ" চাপুন। পরে Settings → Connectivity থেকে বদলানো যাবে।

ধাপ ৮.২: Firebase যাচাই

এই ধাপে phone-এ Internet চালু রাখুন।

  1. "Firebase config paste" চাপুন, ধাপ ৫-এ কপি করা firebaseConfig paste করে "পূরণ করুন" চাপুন। Database URL আর API Key নিজে থেকে বসে যাবে।
  2. Authentication email আর password দিন, ধাপ ৩-এ যেটা তৈরি করেছিলেন।
  3. Database Rules বসানো:
    • "Firebase তৈরি ও Rules-এর সহজ নির্দেশনা" খুলুন, তারপর "নিজের database-এর Rules কপি করুন" চাপুন।
    • Computer-এ Firebase Console → Realtime Database → Rules tab খুলুন।
    • আগের সব লেখা মুছে কপি করা rules paste করুন, তারপর Publish চাপুন।
    • Rules phone থেকে computer-এ পাঠাতে নিজেকে WhatsApp বা email করতে পারেন।
    • কখনো public read/write চালু করবেন না।
  4. চাইলে "সংযোগ পরীক্ষা করুন" চাপুন। কিছু লেখা ছাড়াই সব ঠিক আছে কি না একটা তালিকায় দেখাবে।
  5. "যাচাই করে পরের ধাপ" চাপুন।

ধাপ ৮.৩: Gateway ও বাড়ির Wi-Fi

  1. ESP32 চালু রাখুন। নতুন flash করা ESP32 নিজেই setup Wi-Fi চালু করে। আগে setup করা হয়ে থাকলে BOOT বোতাম ১ সেকেন্ডের মধ্যে ৩ বার চাপুন। Setup Wi-Fi ২০ মিনিট চালু থাকবে।
  2. "ফোনের Wi-Fi settings খুলুন" চাপুন। NoxBrain-XXXXXX Wi-Fi-তে যুক্ত হন, password 85208136।
  3. Phone "Internet নেই" দেখালে "যুক্ত থাকুন" / "Keep connected" দিন। তারপর app-এ ফিরে আসুন।
  4. "Gateway যাচাই করে Home Wi-Fi খুঁজুন" চাপুন। ESP32 যে Wi-Fi-গুলো দেখতে পাচ্ছে তার তালিকা আসবে।
  5. বাড়ির 2.4 GHz Wi-Fi বেছে নিন, তার password দিন।
  6. "Wi-Fi ও Firebase তথ্য gateway-তে পাঠান" চাপুন।

ধাপ ৮.৪: Cloud সংযোগ যাচাই

  1. ESP32 বাড়ির Wi-Fi আর Firebase-এ যুক্ত হলে app জানাবে।
  2. এবার phone-কে আবার বাড়ির Wi-Fi অথবা mobile data-তে ফিরিয়ে নিন।
  3. "Internet থেকে Cloud handover যাচাই করুন" চাপুন। সফল হলে setup Wi-Fi নিজে বন্ধ হয়ে যাবে। ব্যর্থ হলে "Gateway-তে ফিরে configuration সংশোধন" চেপে Wi-Fi password ঠিক করুন।

ধাপ ৮.৫: Controller ও Battery

শুরুর আগে SRNE আর JK-র নিজের app বা অন্য কোনো phone থেকে Bluetooth connection বন্ধ রাখুন। Controller আর BMS একসাথে শুধু একটা device-এর সাথে যুক্ত থাকতে পারে।
  1. Battery mode সেভ করুন: Only Controller Mode হলে Battery type (Flooded / Sealed (AGM) / Gel / Lithium) আর Battery capacity (Ah) দিন। "Battery mode সেভ করুন" চাপুন। "Gateway-এ সেভ করা mode"-এ আপনার mode দেখাবে।
  2. Controller model: তালিকা থেকে নিজের Shiner model বেছে নিন, যেমন Shiner2420।
  3. "Controller খুঁজুন / পরিবর্তন" চাপুন। ESP32 নিজে আশেপাশের Bluetooth device খুঁজবে। SRNE controller সাধারণত BT-TH-… নামে দেখায়। সেটার পাশে "ESP32-তে যুক্ত করুন" চাপুন। প্রথম আসল data পেলে "সংযুক্ত হয়েছে" দেখাবে।
  4. Controller + BMS Mode হলে: JK protocol layout "Auto-detect" রেখে দিন। "BMS খুঁজুন / পরিবর্তন" চাপুন, তালিকা থেকে JK BMS বেছে "ESP32-তে যুক্ত করুন"।
  5. সব ঠিক হলে "Setup সম্পন্ন করে dashboard খুলুন" চাপুন।

ধাপ ৯: Setup-এর পরে প্রথমবার যা সেট করবেন (Settings)

Settings খুলতে username/password চাইলে সেটা আপনার নিজের সেট করা Settings-lock।

General tab

  • Panel Power (W): আপনার মোট panel কত watt-এর। এটা দিয়ে gateway panel-এর Output % হিসাব করে।
  • Battery Capacity (Ah) আর Battery Type: শুধু Only Controller Mode-এ দেখায়।
  • Daily Reset Time: দিনের হিসাব কখন নতুন করে শুরু হবে, default সকাল 7:00।
  • PV Average Start / End Time: দিনের কোন সময়টুকু ধরে panel-এর গড় হিসাব হবে।
  • Save চাপুন। Gateway নিশ্চিত করলে তবেই "saved" দেখাবে।
  • User Access Credentials: Settings-এর lock-এর username আর password এখান থেকে বদলাবেন।

Connectivity tab

  • Battery mode বদলানো, controller বা BMS বদলানো, Disconnect আর Reconnect।
  • Wi-Fi Search: এখনই নতুন Wi-Fi-তে যাওয়া।
  • Wi-Fi Manual: আগে থেকে সর্বোচ্চ ৩টা Wi-Fi save করে রাখা। বর্তমান Wi-Fi না থাকলে ESP32 save করা যেটা কাছে পাবে সেটায় যুক্ত হবে।

Load tab (controller-এর DC Load)

  1. প্রথমবার "Enable controller manual load mode" চাপুন। এরপর থেকে app থেকে Load ON/OFF করা যাবে।
  2. আগের অবস্থায় ফেরাতে "Restore previous load mode" চাপুন, যেমন সবসময় চালু বা light/timer।

Battery tab (controller-এর charge settings)

  1. "Read actual controller parameters" চাপলে controller-এর আসল মানগুলো দেখাবে।
  2. মান বদলানো যায় শুধু battery type USER হলে। অন্য type হলে "Change controller battery type to USER" দিয়ে বদলাতে পারবেন।
    বদলানোর আগে battery প্রস্তুতকারকের দেওয়া voltage মানগুলোর সাথে প্রতিটা মান মিলিয়ে নিন। Voltage-এর ঘরে 12V system অনুযায়ী মান দিতে হয়। যেমন 24V battery-র জন্যও 14.4 লিখবেন, 28.8 না।

Update tab

নতুন firmware বা app version থাকলে এখান থেকে update করুন। Firmware update নিজে থেকে হয় না, আপনি চাপলে তবেই হয়।

Cloud tab

অন্য Firebase project-এ সরে যেতে হলে এখান থেকে করবেন।

ধাপ ১০: প্রতিদিনের ব্যবহার

  • Home: Panel, Battery, Load-এর live মান, Alerts, আজকের energy। Only Controller Mode-এ হিসাব করা মানের পাশে "হিসাব করা" লেখা থাকে। Controller + BMS Mode-এ BMS-এর data না আসা পর্যন্ত Battery-তে "Loading" দেখায়।
  • Statistics: আজ, গতকাল আর আগের দিনের হিসাব, সর্বকালের আর আজকের সর্বোচ্চ panel output।
  • Alerts: controller-এর fault (যেমন Load short circuit, Battery over-voltage), BMS-এর data না আসা, model না মেলা ইত্যাদি।

ধাপ ১১: সমস্যা ও উদ্ধার

  • নতুন phone, বা আবার setup: ESP32-এর BOOT বোতাম ১ সেকেন্ডে ৩ বার চাপুন। Setup Wi-Fi ২০ মিনিট চালু থাকবে, এর মধ্যে app-এ Setup চালান। আগের data হারাবে না।
  • Wi-Fi বা বিদ্যুৎ চলে গেলে: ESP32 নিজে বারবার আবার যুক্ত হওয়ার চেষ্টা করে। Setup Wi-Fi নিজে থেকে খোলে না।
  • সব মুছে নতুনের মতো করা (Factory reset): BOOT বোতাম টানা ১০ সেকেন্ড চেপে ধরে রাখুন। ESP32-S3-এ লাল আলো জ্বলে-নিভে সময় গুনতে থাকবে। Firmware থেকে যাবে, বাকি সব setting মুছে যাবে।
